# Algorithm Battle – Which Data Structure Wins?

Student Record Management System comparing:
- Binary Search Tree (BST)
- AVL Tree
- Hash Table using Linear Probing

## Compile and run

```bash
gcc -std=c99 -Wall -Wextra student.c -o student
./student
```

## Dataset

The program starts with 30 sample student records (IDs 1001–1030), with
student name, department, and marks. The dataset is initialized in `student.c`.
